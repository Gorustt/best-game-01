LUMEN KEEP — a top-down arena defence game: hold the last beacon against the Dusk Swarm for 10 waves. Built for make.fun's "Make the best game" bounty.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 — WASD to move, mouse to aim, hold click to fire, Space to dash.
